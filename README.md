# FaveFigs.com

- **Write blog posts:** go to https://favefigs.com/admin and log in with GitHub.
- **Figs, reviews, Hello bubble:** edit the Google Sheets (links are in `site/settings.js`).
- **Site settings** (links, email, analytics): `site/settings.js`.

Netlify rebuilds the site automatically whenever anything here changes.

Folders:
- `site/` – the home page, styles, settings, images
- `content/blog/` – blog posts (written by the editor)
- `images/uploads/` – photos uploaded in the editor
- `admin/` – the blog editor
- `build.js` – turns posts into pages (no need to edit)
