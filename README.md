# FaveFigs.com

- **Write blog posts:** go to https://favefigs.com/admin and log in with GitHub.
- **Figs, reviews, Hello bubble:** edit the Google Sheets (links are in `settings.js`).
- **Site settings** (links, email, analytics): `settings.js`.

Netlify rebuilds the site automatically whenever anything here changes.

The blog editor saves posts in `content/blog/` and photos in `images/uploads/` (it creates these folders itself).
`build.js` turns posts into pages; no need to edit it.
